# V23.5.0 — JYC Hub Identity Pass

Every published JYC hub now has a restrained, domain-specific visual signature while remaining inside the single JYC light/dark design system.

## 21 community identities
- Cultural: Fortissimo, BDS, VamUnique, Panache
- Technical: RPH, CICR, Innovation, Zencoders, JODC, CypherX, Arcadia, Neural Nexus, GDG, Dronotics
- Creative: Aakriti, Aura, Cinekala, Abhivyakti, Prismatic
- Literary: Eloquence
- Sports: JSA

Each identity defines an accent, motif, signature and domain traits. Detail pages and directory cards use these values without introducing separate themes or unrelated branding.

## Safety
- Supplied hub content remains the source for descriptions.
- Current operational details are not invented.
- Light and dark modes keep their separate JYC identities.
- Reduced motion remains supported.
