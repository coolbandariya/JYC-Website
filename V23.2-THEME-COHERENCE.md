# V23.2 — Theme Coherence / Readability / Source Review

This release adds a canonical public visual layer loaded after the legacy V13–V24 stylesheets.

## Fixed
- Light/dark public text and surface contrast is explicit.
- Legacy red/pink atmosphere is neutralized in the public shell.
- Persistent nav, Home route, theme control and search control use one visual system.
- Hero uses the layered JYC Falcon artwork; the supplied robot GLB is not used in the hero.
- Bot keeps roll/wave/bounce/jump behaviour and uses the supplied bot GLB.
- Assistant opens in the centre.
- Public empty states are compact and readable.
- Supplied `photos.zip` leadership campaign images are used for team profiles and exposed in the gallery fallback.
- Public typography and spacing are tightened to reduce empty space and oversized headings.
- Filter panels remain collapsed until explicitly opened.
- Reduced-motion and overlap guards remain enabled.

## Source basis
The supplied JYC hub PDFs are used for JYC purpose, activity areas, hub families and major event programme content. The supplied previous JYC releases and supplied website ZIPs were reviewed for interaction and information architecture patterns; their visual systems are not copied into JYC branding.
