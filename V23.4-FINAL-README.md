# JYC Website V23.4.0 — Organisation Edition

This release keeps the public site explicitly as the **JIIT Youth Club website**, not a student help portal.

## Public identity
- JYC communities / hubs
- JYC events and fests
- JYC people and leadership
- JYC visual stories and archive
- official JYC contact / social connections
- Agentic AI featured-event bridge

## Editorial additions
- JYC Stories visual editorial layer sourced from supplied hub presentations
- source-backed organisation structure on About
- archive collage using supplied hub photography
- richer hub detail pages with supplied source stories and photographs
- public recruitment route for officially opened club recruitment
- event/fest/archive connections

## Public portal boundary
My JYC, Planner and saved/follow controls are not surfaced in the public editorial navigation. Legacy/private routes remain for compatibility but are not part of the public JYC presentation.

## Build
```powershell
npm ci
npm run qa
npm run build
npx playwright install chromium
npm run qa:browser
```
