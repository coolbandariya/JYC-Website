# V23.6 Reference Integration Pass

This pass was applied **to V23.6 only**. V65 and the supplied club repositories were used as reference material; their code was not made the new base version.

## Ported patterns

- Compact visual context rail inspired by the V65 page-shell pattern.
- Dense event list view inspired by V65's event directory rows.
- Event programme/timeline + community connection retained and tightened using event-site references.
- Global search, archive and people/event relationship patterns remain first-class JYC content rather than a productivity dashboard.
- Domain-specific hub motifs remain within one JYC paper/night visual system.

## Theme / interaction guardrails

- Public club pages are locked to the JYC visual theme; legacy cyberpunk/neon/alternate club palettes cannot take over the public site.
- Fest visual theme switching is locked to the JYC theme while programme/filter functionality remains.
- Custom cursor, orbit decoration, flying-bird layers and secondary Phoenix artwork are disabled in the public shell.
- Reduced-motion, focus-visible, overflow and mobile layout safeguards remain active.
- No red/pink/bright-cyan identity tokens were introduced in the canonical V23.6 layer.

## Production build note

A production Vite build was attempted. The available extracted `node_modules` contains only the Windows Rolldown optional binding while this execution environment requires the Linux native binding. `vite build` therefore stops inside Rolldown before compiling the application. This is an environment/dependency-install limitation, not a source-QA pass being reported as a successful production build.

Run locally after a clean install:

```bash
npm ci
npm run qa
npm run build
npm run dev
```

For browser QA:

```bash
npx playwright install chromium
npm run qa:browser
```
