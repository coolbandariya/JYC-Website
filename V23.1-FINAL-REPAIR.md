# JYC Website — V23.1 Final Repair

This release keeps the V23 package version at 23.0.0 for repository compatibility while applying the final public-experience repair pass.

## Public UX repair
- Added a visible Home item to the persistent top navigation.
- Restored an explicit Day/Night control in the navigation.
- Light and dark modes now have separate navigation, surface, text and atmosphere identities.
- Removed the legacy red visual accent from public UI and remapped it to the JYC antique-gold family.
- Removed the custom cursor implementation from the public shell.
- Removed the old central ecosystem/Falcon duplicate from the homepage.
- Kept one hero Falcon treatment behind the hero typography, with layered depth/parallax for a 3D-style presentation.
- The supplied robot GLB is used only by the assistant bot; it is never used as the hero Falcon.
- Assistant panel is centered when opened.
- Assistant bot remains animated with roll, wave, bounce and jump behaviours.
- Filters remain closed until explicitly opened.
- Gallery uses a compact Pinterest-inspired masonry/editorial collage.
- Team uses supplied photos.zip campaign assets in a collage layout.
- Home now includes supplied JYC hub-material photo collages.
- Public fallback content merges with empty/cached/Supabase content so a fresh local/GitHub build does not render empty public directories.
- Home activities use the six documented JYC activity areas from the supplied hub material when no CMS activities are published.

## Source material used
- Supplied `photos.zip` for leadership imagery.
- Supplied JYC hub PDFs for event/photo collages and activity language.
- Existing V20/V21/V22/V23 source and visual system.
- Supplied Agentic AI website ZIP for persistent-navigation/active-indicator inspiration.
- Supplied CICR, Innovation and JODC ZIPs were reviewed for structure, event discovery and visual/product patterns; their unrelated branding was not copied into JYC.

## Build note

```bash
npm ci
npm run qa
npm run build
npx playwright install chromium
npm run qa:browser
```
